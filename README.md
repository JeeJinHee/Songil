# 손길 (Songil)

**시각장애인의 키오스크 이용을 돕는 Android 앱**  
컴퓨터공학과 졸업 프로젝트 · 33조 지진희팀

손길은 사용자가 원하는 주문을 말하면, 휴대폰 카메라로 현재 키오스크 화면을 인식하고 다음 버튼까지 손끝을 음성과 진동으로 안내하는 서비스입니다. 버튼을 누른 뒤에는 화면 변화를 확인해 다음 단계의 안내로 이어가는 것을 목표로 합니다.

## 초기 개발 범위

- 학교 키오스크 1종에서 대표 주문 과업 검증
- 음성으로 주문 목표 입력 및 확인
- 현재 화면의 버튼 이름·위치와 손끝 위치 인식
- 목표 버튼 안내 및 선택 결과 확인
- 화면이나 손끝을 인식하지 못했을 때 재시도 안내

버튼 **위치는 미리 등록하지 않고 현재 카메라 화면에서 인식**합니다. 초기 검증은 정해진 촬영 조건과 메뉴·옵션을 대상으로 진행하며, 결제 안내와 다른 매장 지원은 이후 범위입니다.

## 시스템 구성

| 담당 | 역할 | 주요 기술 |
|---|---|---|
| FE | Android 앱, 카메라·음성·진동 입력과 안내 화면 | Kotlin, Jetpack Compose, CameraX |
| BE | 세션과 주문 목표·진행 단계 관리 | FastAPI, PostgreSQL, SQLAlchemy, Alembic |
| AI | 키오스크 화면·버튼·손끝 인식 | ML Kit OCR, MediaPipe 등 검토 |

FE·BE·AI는 합의한 API와 인식 결과 형식을 통해 연결합니다. 기술 구성은 구현 및 실험 결과에 따라 변경될 수 있습니다.

## 현재 진행 상황

- BE: 서버 초기 구성 및 Session 생성·조회·종료 API 구현
- FE: 사용자 흐름 및 화면 와이어프레임 설계
- 공통: 루트 `.gitignore` 추가

각 기능의 구현 상태와 실행 방법은 개발이 진행되는 대로 갱신합니다.

## 협업 방식

- `main`: 검증된 시연 버전
- `dev`: FE·BE·AI 작업 통합
- `feature/{담당자}-{작업명}`: 개별 작업

작업 브랜치는 최신 `dev`에서 생성합니다. 작업 완료 후 `dev`로 PR을 열고, 작성자 외 팀원 한 명의 리뷰를 받은 뒤 머지합니다. 마일스톤의 통합 동작을 확인하면 `dev`에서 `main`으로 반영합니다.

## 파일 관리

API 키, 비밀번호, `.env`, 촬영 원본, 음성 데이터, 대용량 모델 파일은 Git에 올리지 않습니다. 실행에 필요한 환경변수는 실제 값을 제외한 예시 파일로 공유합니다.
